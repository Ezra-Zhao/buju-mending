# 补苴集 · 衣服维修与自制

「补苴」二字出自韩愈《进学解》：「补苴罅漏，张皇幽眇。」罅是裂缝，苴是鞋底垫草——补苴就是把破的地方补好、把漏的地方堵上。这本小集子讲的就是这件事：一件衣服破了、开了线、拉链坏了、扣子掉了，怎么自己动手修好；修无可修，怎么改个尺寸、换个用途，让它多穿几年。

衣服是文明最基础的产物之一。一台缝纫机、一根针，背后是纺织、制衣、材料一整条链。本集归在「文明重启文库」生活层（L0/L1）：不追求裁缝店的工艺精度，只求普通人在家里、用便宜工具、把八成常见毛病处理掉。

## 适用人群

- 衣服有小毛病（开线、掉扣、破洞、拉链卡死），送裁缝店嫌贵、嫌等，自己动手更快的
- 想改裤长、收个腰，但没摸过针线、不知道从哪下手的
- 家里旧衣成堆，扔了可惜，想改成袋子、抹布、坐垫继续用的
- 对量体裁衣感兴趣，想从开源软件入手学打版的

不需要任何基础。先从第二章的针法练起，拿旧衣服当练习布，缝坏了拆掉重来，成本为零。

## 工具总清单（详见第 01 章）

最低配置，人人家里都该备一盒：

| 类别 | 物品 |
|---|---|
| 针线 | 手缝针（多型号一盒）、缝纫线（黑/白/灰/藏青四色先行）、拆线器 |
| 裁剪 | 布剪一把（只剪布，别剪纸）、小线剪 |
| 固定 | 珠针一盒、安全别针、划粉或水消笔 |
| 辅助 | 顶针、软尺、直尺、熨斗与烫衣板 |
| 辅料 | 松紧带、衬布（粘合衬）、备用扣、备用拉链 |

进阶（按需要添置）：缝纫机、织补蘑菇或绣绷、锁边液、皮革针、弹力布专用针。

## 使用方式

按顺序读，或者直接按毛病查章节：破洞看 02、03、04；拉链坏了看 05；裤子长了看 06。所有步骤都按「先在废布上试一遍，再上正衣」的顺序写——这是缝补这行当的老规矩，能省一半返工。
